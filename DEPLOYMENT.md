# CRYPTOPILOT — V0.1

Адаптивный локальный криптопортфель. Запуск: `python -m http.server 8080`, затем `http://localhost:8080`. Данные хранятся в браузере. Для переноса используйте экспорт/импорт JSON в разделе «Данные». Портфель при первом запуске пуст; личные сделки и API-ключи не входят в код.

## Учёт
Ввод P2P RUB→USDT и спотовых покупок/продаж по биржам, комиссий, ручных котировок и курсов. RUB-себестоимость переносится средневзвешенным методом отдельно по биржам; если история P2P неполная и курс не указан, себестоимость неизвестна. Изменение за 24 часа — изменение цены текущих остатков, не доходность с поправкой на денежные потоки. График использует введённые точки и линию средней покупки. Целевые доли BTC 70%, ETH 15%, SOL 5%, GRAM 5%, ZRO 5% — настраиваемые.

## HTX
Экспериментальный скрипт `htx_import.py`: экспортируйте JSON из приложения, задайте локально переменные окружения HTX_ACCESS_KEY и HTX_SECRET_KEY (только чтение), запустите `python htx_import.py backup.json updated.json --order ORDER_ID --quotes`. Импортируйте updated.json. Сетевой импорт не проверен; P2P, RUB и 24h пока вручную. Время API UTC; проверьте часовые пояса. Не передавайте ключи в браузер или GitHub.

## GitHub Pages
В Settings → Pages выберите Deploy from a branch → main → /(root) → Save, если тариф поддерживает Pages для закрытого репозитория. Публикуемый сайт не содержит личных сделок. Не меняйте видимость репозитория без согласования. GitHub Pages обслуживает только статический интерфейс, не backend.
